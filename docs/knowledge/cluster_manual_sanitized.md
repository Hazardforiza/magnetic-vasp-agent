## 仍需用户或管理员确认

以下信息确认后应写入独立的、无凭据的普通用户手册，而不是从维护手册中猜测：

- 当前应执行的 VASP 模块加载方式，以及 `vasp_std`、`vasp_ncl`、`vasp_gam` 的实际路径；

- 组内如何判断节点可用、如何登记占用，以及是否允许多用户共享节点；
- 批准的远端计算根目录、配额和结果保留规则；
- 当前是否存在任何调度或预约机制，即使它不是 Slurm；

在这些问题得到确认前，本文件只能作为“待核实线索”被检索，不能覆盖 `config/execution/cluster.json`、节点白名单或用户当次审批。
