# 集群站点与执行策略

本文件规定项目使用集群时的通用安全边界，不代表任何真实站点的授权、节点清单或软件部署信息。实际主机、节点白名单、模块与路径必须由集群管理员提供，并写入本机或受控部署中的 `config/execution/site.team.json`。

- 站点模板中的示例地址、节点和软件路径不可直接用于连接真实集群。
- 登录网关仅用于身份验证和转发；不得在网关上运行 VASP、MPI 或其他计算任务。
- 只允许访问 profile 明确列出的计算节点；未列出的节点及历史记录都不构成授权。
- 节点负载、进程列表和 CPU 拓扑只是瞬时观察，不是资源分配或独占证明。
- 每位使用者仅使用自己的身份、密钥与远端专用目录；不得读取、修改、覆盖或停止他人文件和作业。
- 远程执行默认关闭。每次执行必须通过输入审核、资源批准、只读 probe、固定 MPI smoke、受控传输校验和单次启动批准。
- 密码、私钥、API key、POTCAR 正文及未经脱敏的运行数据不得进入 Git、知识库或 LLM 提示。
- Agent 不得生成任意 shell、绕过审批、自动抢占资源、重试或取消其他人的作业。
