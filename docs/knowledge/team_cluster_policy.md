本文件记录用户已经确认的运行边界，供 RAG 引用和人工审查。真正的强制执行仍由 `config/execution/cluster.json` 和 execution 模块完成。

- SSH 入口为 `zyy@192.168.164.203:22`，进入后是 `mu01`。
- `mu01` 只允许作为跳板，禁止在其上启动 VASP、MPI 或其他计算任务。
- 允许使用的计算节点仅为 `cu21`、`cu22`、`cu23`、`cu41`、`cu42`、`cu43`、`cu48`、`cu49`、`cu50`。
- 集群没有 Slurm；目标运行方式是在获批的单个计算节点上使用 Intel MPI 和 VASP 5.4.4。
- 节点负载快照不等于资源分配。真实启动前必须由用户确认组内使用规则和空闲窗口。

- 当前 `execution_enabled=false`，远端专用 `remote_root` 尚未确认，不能上传或启动计算。
- `cu21` 已观察到被其他用户占满物理核心，在新的人工确认前不得用于测试。
- LLM 可以解释预检结果和提出计划，但不能选择白名单之外的节点、生成任意 shell、绕过审批或自动重试。
