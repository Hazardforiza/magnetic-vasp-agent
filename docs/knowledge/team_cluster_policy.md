# 示例 VASP 集群策略模板

本文件记录可供复制的**示例**运行边界，供 RAG 引用和人工审查。它不绑定某一个集群账号，也不描述本组真实网络。部署前必须由管理员把示例值替换成经过批准的站点模板；真正的强制执行由站点模板与每人本机合成的 `ClusterProfile` 完成。

- 示例跳板短主机名是 `login01`。示例工位电脑连 `gateway.example.org:22`；示例本机隧道为 `127.0.0.1:2222`。登录后仍必须验证主机为部署 profile 中的跳板名、用户为**当前操作者自己的账号**。
- `login01` 只允许作为跳板，禁止在其上启动 VASP、MPI 或其他计算任务。计算节点之间的内部 SSH 端口由实际站点策略决定，不能从本模板推断。
- 示例允许使用的计算节点仅为 `node01`、`node02`。部署方必须用管理员确认的白名单替换它们；历史资料中的节点名称不构成授权。
- 示例目标运行方式是在获批的单个计算节点上使用 Intel MPI 和 VASP；版本和路径必须由实际站点确认。
- 每人使用自己的远端目录 `/home/<user>/magvasp/runs`。不得把别人的家目录写进 profile，不得查看、修改、信号或取消其他用户的作业。
- 节点负载快照不等于资源分配。任何节点在启动前都必须用最新 probe 和人工资源批准确认。
- 站点模板可以共享；用户名、连法、是否启用执行、密钥和密码必须留在本机 identity / SSH 里。
- LLM 可以解释预检结果和提出计划，但不能选择白名单之外的节点、生成任意 shell、绕过审批或自动重试。

- 用户提供的 topsst.sh 会并行查看这些节点的 top/sensors；它只能作为占用参考，不能替代 probe 或资源分配。


- 站点提供的 topsst.sh（如有）只是节点占用查看参考；Agent 可在受控路径下调用它生成候选，但仍必须经过 probe 和人工资源审核。

- 站点提供的 VASP 任务准备/提交脚本（如有）只能作为人工参考；固定命令模板不作为 Agent 的可执行入口。
