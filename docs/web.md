# 本机网页使用说明

网页是每位使用者在自己电脑上启动的 MagVASP 工作台，地址固定为本机回环接口。将源码放到 GitHub 只方便组员安装更新，不会自动提供可远程访问的在线服务。

## 首次准备

在仓库根目录使用 Python 3.11 和 `uv`：

```powershell
uv sync --extra agent --extra web --frozen
uv run --extra agent --extra web --frozen magvasp doctor
```

生成计算输入还需要本人获授权的 POTCAR 库。先扫描为本机注册表；网页只使用该注册表选择和核验赝势，不在审核页显示 POTCAR 正文：

```powershell
uv run --extra agent --extra web --frozen magvasp potcar scan `
  --root "C:\path\to\potpaw_PBE.54" `
  --family PBE_54 --output var\potcar_registry.json
```

使用自然语言 Agent 时，从 `config/agent/llm.example.json` 建立本机 `config/agent/llm.json` 并配置模型服务。API key 可填入本机 `llm.json` 的 `api_key` 字段，也可通过配置指定的环境变量提供；每位组员使用自己的模型凭据。集群执行还需按 [`member_setup.md`](knowledge/member_setup.md) 配置自己的 SSH 身份和站点模板；网页不会代管集群密码。

## 启动与使用

```powershell
uv run --extra agent --extra web --frozen magvasp web `
  --profile config\execution\cluster.json
```

默认打开 `http://127.0.0.1:8765`。浏览器没有自动出现时可手动打开该地址。端口占用时使用 `--port 8766`；不希望自动打开浏览器时加 `--no-browser`。按 `Ctrl+C` 停止本机服务。

- **项目**：上传一份 `.mcif` 或 `.cif`，选择静态 SCF、结构弛豫、磁序候选比较、ENCUT/k 点收敛或磁各向异性 MAE。静态 SCF 可附加依赖其 CHGCAR 的 DOS 步骤。磁序比较生成有界的共线翻转候选；收敛任务生成独立的 ENCUT 和 k 点扫描；MAE 生成 [001]、[100]、[110] 三个 SOC 自洽方向，仅接受共线 mCIF。每个选项都会经过同一套 POTCAR、INCAR、KPOINTS、依赖关系和哈希校验。生成后逐项查看 POSCAR、INCAR、KPOINTS、赝势名称和哈希；由具名审核人接受、退回或要求修改。接受输入只代表这一版输入通过人工审核，不是启动集群作业的授权。Band 需要用户提供实际磁性晶胞的高对称路径，暂不从 mCIF 自动猜测。
- **Agent**：输入计算目标；已配置模型时创建本机会话。工具需要批准时，页面显示待审批调用，由具名审核人逐项决定后继续。实时探测、资源批准、smoke、传输、启动仍受原有分级审批和运行证据约束。
- **节点**：从本机 `ClusterProfile` 的计算节点白名单中选择节点，手动刷新固定只读探测，查看 CPU、负载、可用内存、VASP 运行时和 Wannier90 能力摘要。列表排除站点配置中的网关；页面显示的状态是瞬时观察，不代表资源分配、独占或启动授权，也不会因为选择节点而提交计算。
- **结果**：导入 `OSZICAR`、`OUTCAR`、`vasprun.xml` 等允许文件，查看收敛和磁矩解析结果。如果同时提供 `TDOS.dat`，页面绘制 DOS；能带图需要 `BAND.dat` 或 `REFORMATTED_BAND.dat`，以及 `KLABELS`。仅导入 `vasprun.xml` 不会自动产生 DOS/能带图。上述绘图表格可由 Linux/WSL 中的 VASPKIT 或其他兼容流程预先生成。
- **知识库**：导入文献、整理案例，确认索引后检索来源摘录；支持本机资料和指向同一共享文件夹的组内资料。使用方法见下文。
- **环境**：查看本机 POTCAR 注册表、Agent 模型和集群 profile 的就绪状态。

## 项目的节点与核数

在“生成输入方案”的“计算资源”中，可以选择“手动指定”或“由 LLM 选择”：

- **手动指定**：从本机配置的计算节点白名单选择提交节点，填写物理核数（每个物理核对应一个 MPI 进程）。点击“检查节点状态”可读取该节点的负载、内存和可访问物理核数；这里只做观察，不提交作业。网关不可作为计算节点。
- **由 LLM 选择**：生成项目时先保存这一偏好。生成后在项目详情点击“让 LLM 选择”，服务会只读探测白名单节点，将符合要求的节点摘要和项目规模交给已配置的模型选择。模型返回后会重新探测所选节点，并校验节点、物理核数和 VASP 环境。没有可验证节点、模型不可用或返回非法结果时会明确报错，不会伪造自动选择结果。

项目详情的“计算资源”也支持修改已有项目。保存偏好会清除旧资源方案；修改资源不改变 POSCAR、INCAR、KPOINTS、POTCAR 或它们的输入审核记录。资源偏好与检查结果保存在项目目录的 `resources.json`，重启网页服务后仍可读取；检查结果会显示观察时间，后续规划仍需新鲜探测。

得到资源方案后，可以点击“交给 Agent 规划”。当前网页为项目的第一个计算步骤生成固定执行请求，资源卡片显示该规划步骤；不会自动启动或连续执行项目的全部步骤。该项目会话的工具绑定保存的节点、核数、CPU 集合、计算步骤、输入目录和集群配置，只能检查和生成计划。修改资源后，旧项目会话不能继续沿用旧方案，需要重新规划。页面选择资源不会授予资源使用权或启动计算；正式执行继续遵循已有的输入审核、具名资源授权、smoke、传输与启动检查。

项目、审核记录和导入的结果保存在 `var/web/`，该目录不纳入 Git。Agent 会话及暂停状态目前只保存在服务进程内，重启网页服务后不能从原会话继续。网页尚无首次配置向导、统一集群作业列表或多人账号体系；每人需在自己的电脑上运行。服务只监听 `127.0.0.1`，不要将其作为公网或组内共享服务部署。

导入的 `TDOS.dat`、`BAND.dat`、`REFORMATTED_BAND.dat` 和 `KLABELS` 目前是独立外部表格，网页尚未核对它们与同批 VASP 输出的计算来源、费米能参考或 k 路径是否一致。图像可用于查看这些表格，但不能仅凭同次上传就认定它们属于已解析的 VASP 结果；正式分析前应人工核对来源和能量参考。

## 给组员共享源码

建议使用审查过的 GitHub 私有仓库分发源码。每位组员在自己的电脑上安装依赖，扫描自己的授权 POTCAR 库，配置个人模型密钥和集群身份。源码仓库不应包含 `.env`、`config/agent/llm.json`、个人 `cluster.json` / `identity.json`、POTCAR、运行结果、原始课程资料或 VASPKIT 发行包。VASPKIT 的发行许可证要求未经书面许可不得再分发。

## 本地知识库与共享知识库

“知识库”页面中的本地库保存在当前网页数据目录的 `knowledge/` 下，默认是 `var/web/knowledge/`。它独立于命令行已有的 Wiki/Reference_Demo 索引；已有目录不会被网页自动扫描或发布。复制源码到新电脑不会自动带上本地库，迁移时需在服务停止后备份、复制完整的知识库目录。

共享库默认未配置。在页面填写一个已经存在、当前 Windows 用户可以访问的共享文件夹，例如 `\\fileserver\research\magvasp` 或映射盘 `Z:\magvasp`。程序只在该目录内维护专用的 `magvasp-knowledge` 子目录，不扫描其中的其他文件。组员在各自电脑启动网页，配置指向同一实际文件夹的路径，即可检索同一共享库；各电脑的盘符可以不同。先通过 Windows 文件管理器确认该目录可访问，需要 VPN、组内网络或文件共享身份时由操作系统建立连接。共享库不依赖计算节点 SSH，也不要求在 `login01` 上运行服务。

共享目录应提供可靠的文件锁和原子重命名（例如正常配置的 SMB 共享）。跨电脑同时入库通过文件锁串行更新，索引写完后才切换活动快照。独立的两份本地目录、异步网盘同步文件夹不会自动成为一致的共享库。共享库的读写权限由文件服务器控制；页面尚无组员账号、逐条授权或管理员审批系统。共享路径失效时页面会提示，本地库仍可使用。

文献可导入 PDF、Markdown、TXT、BibTeX，单文件上限 20 MiB。先预览解析正文、补充标题/DOI/标签，再点击确认入库；草稿不进入检索。PDF 支持可提取的文本和页码引用，扫描件需要先在外部 OCR，损坏或加密文档会明确报错。修改 PDF 正文后会清除原页码映射，避免引用已经不对应的页面。当前库保存解析文字、分页和来源信息，原始 PDF 请另行备份。BibTeX 检索的是条目文本，不会自动下载论文全文。原始 POTCAR 和 VASP 输出不能作为文献入库。

案例可记录自己的方法、结果和排错经验，也可以关联已有项目/结果，附入输入审核状态、参数与自动解析的收敛摘要及来源哈希。关联来源保存为单独的只读快照；编辑笔记不会改写快照。检索摘录会区分笔记、项目快照和结果快照。关联由用户指定，系统不据此认定某结果就是该项目的输出。输入被接受、计算收敛、资料已索引都不等于人工科学验证；本版案例统一保留“未人工验证”状态。

本地条目只有在用户点击“发布到共享库”后才复制到共享库。发布后的共享副本独立保存，之后修改本地内容不会静默覆盖共享副本。也可直接在共享库导入资料。共享库中的来源是组员提供的参考材料，不应当作程序执行指令。

检索使用本机 BM25，不下载嵌入模型。普通 Agent 和项目 Agent 均可通过只读的 `knowledge.library_search` 检索当前活动的本地/共享索引，返回来源、摘录和可用的 PDF 页码；新增入库后无需重启。被检索的摘录会提供给当前配置的 LLM，因此“本地库”表示保存位置，不表示摘录绝不离开电脑。入库不训练或微调模型。该工具不增加计算权限，项目会话仍只能在既定资源约束内检查与规划。
